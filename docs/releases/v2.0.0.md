# Release notes: v2.0.0

These notes describe the published Music Converter v2.0.0 release. They are a historical record; current browser support is documented in [Browser and platform support](../guides/browser-support.md). The published release included Chrome and Edge extension assets. Edge support has since been retired.

## Changes in v2.0.0

- **Extension-first redesign:** the browser extensions used a shared SSOT core and an isolated content script. The local Node.js server was removed.
- **Removed local components:** the server, USB bridge, startup script, and Windows packaging were removed from the active product.
- **Manual console helper:** the release included script_complet.txt for manual use in DevTools. Automatic userscripts such as Tampermonkey were unsupported.
- **User-triggered downloads:** downloads were initiated by a user action through a browser link or DOM anchor, without the chrome.downloads permission or a background download API.

## Retired v1 environment variables

The v1 environment variables were removed without replacement:

- PORT
- NO_OPEN
- MUSIC_CONVERTER_EXTENSION_ORIGINS
- MUSIC_CONVERTER_USB_VOLUME_ID
- MUSIC_CONVERTER_USB_MOVE_SOURCE
- MUSIC_CONVERTER_USB_MOVE_DESTINATION
