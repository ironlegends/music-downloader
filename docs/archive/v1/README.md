# Historical v1 records

This archive preserves the plans, designs, guides and validation records for retired v1 components. It includes the former local server, launcher, USB bridge, browser targets and distribution formats. Their commands, technical identifiers and historical artifact names describe that period and may refer to files absent from the current checkout. Exact historical response payloads and third-party or sample values remain unchanged in quoted examples.

For the active Chrome extension, use the [current README](../../../README.md) and [browser support guide](../../guides/browser-support.md). The current manual helper is `console-script.js`; older names in these records remain historical references. Published release records retain their original version and asset inventory.

Links to earlier private issues or commits may require access to the legacy repository. Those records are not imported into the public repository's history or issue tracker.

The current source is covered by the [root MIT license](../../../LICENSE). Current release and publication gates are recorded in the [readiness report](../../security/open-source-readiness.md).
