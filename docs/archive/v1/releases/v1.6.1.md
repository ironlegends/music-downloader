## v1.6.1 security, reliability, and hardening

- **ZIP packaging and POSIX:** Unix code (0x0314) in the central directory header preserves exact 0644 permissions.
- **SPDX 2.3 SBOM:** made the version dynamic in software inventory generators.
- **MV3 service worker:** integrated WebCrypto HMAC signing to authenticate local bridge requests.
- **Memory management and cleanup:** actively purged expired failed origins in the bridge authentication component.
- **Anti-SSRF:** expanded filtering to block CG-NAT (100.64.0.0/10) and benchmarking (198.18.0.0/15) subnets.
- **Session engine and runner:** supported the polling -> polling transition for continuous progress and synchronized onChange with the UI.
- **Accessibility and focus:** aggregated messages in the ARIA live region and targeted the exact tagName when restoring focus.
- **Windows USB containment:** fixed root detection (E:\), added collision reservations, and dynamically reassigned the mount.
- **Artifact verifier:** added strict isFile() checks against directories and path traversal.
